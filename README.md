# 📄 Landing Page - Dr. Bernardo Almeida | Odontologia Premium

Landing page de alta conversão para clínica odontológica premium em Santo Amaro - SP. Desenvolvida com **HTML5**, **Tailwind CSS (CDN)** e **JavaScript Vanilla**, com formulário integrado via **Web3Forms** e botão interativo do WhatsApp.

---

## 🚀 Tecnologias Utilizadas

- **HTML5 & Semântica**: Estrutura acessível e otimizada para SEO.
- **Tailwind CSS**: Estilização moderna e responsiva.
- **Vanilla JavaScript**: Interatividade, animações e validação dinâmica de campos.
- **Web3Forms API**: Envio assíncrono (AJAX / Fetch) de mensagens de contato.
- **Google Fonts**: Tipografias *Cormorant Garamond* e *Plus Jakarta Sans*.

## 🛠️ Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/bernardoaoliveora/dentista-dr-bernardo.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd dentista-dr-bernardo
   ```
3. Abra o arquivo `index.html` em qualquer navegador web de sua preferência ou utilize uma extensão como Live Server no VS Code.

---

## 🔐 Configuração do Web3Forms

O formulário de contato utiliza a API do Web3Forms para encaminhar mensagens sem recarregar a página. A chave pública de acesso (`access_key`) encontra-se configurada no campo `<input type="hidden" name="access_key">` dentro do `index.html`.
